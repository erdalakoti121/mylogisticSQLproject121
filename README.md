# Logistics & Supply Chain SQL Project

## Project Overview
Performed logistics and supply chain analytics using SQL on a shipment dataset containing 2500+ records.

## KPIs Analyzed
- On-Time Delivery %
- Warehouse Performance
- Fuel Cost Contribution
- Shipment Trends
- Delay Analysis
- Route Efficiency

## SQL Concepts Used
- Window Functions
- ROW_NUMBER()
- Rolling Averages
- GROUP BY & HAVING
- Subqueries
- Conditional Aggregation

## Tools Used
- MySQL
- GitHub
